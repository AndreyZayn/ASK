# Projects Index

One note per owner-enrolled project, using `kind: project`. State its goal, current status, next step, sources, and linked decisions (`kind: decision`). Do not infer project facts from task names.

This catalog is intentionally empty. Add your own notes locally in this folder and link each one here.

Routing: [[knowledge-map]]

For a project that grows beyond one note, use `Projects/<Project>/INDEX.md` and a local retrieval map. Create only needed layers: vision, product, experiences, decisions, schemas, prompts, research, marketing, go-to-market, brand, fundraising, and software. A software portfolio links each owned codebase and its actual repository contract. A development log records lifecycle evidence separately from human-facing product knowledge. Register the local `project` identifier and any domain or tag vocabulary in the schema before use.
