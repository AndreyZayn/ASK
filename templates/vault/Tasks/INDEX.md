# Tasks Index

Task lists use `kind: task-list`; daily plans use `kind: daily-plan`. Move items between state notes without duplicating their authoritative state:

- [[Tasks/Backlog]] — proposed, not yet active
- [[Tasks/Active]] — selected, not started
- [[Tasks/In-Progress]] — underway
- [[Tasks/Blocked]] — waiting on a named blocker
- [[Tasks/Done]] — completed, with outcome
- [[Tasks/Daily/INDEX]] — date-routed plans, only when requested

No task records are enrolled. Keep durable decisions in the owning project or topic note, not only a task line.
