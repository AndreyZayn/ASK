# Memory Index

Memory notes use `kind: memory` and record context that should outlive a single session. Prefer the owning project or topic note for decisions and state.

- [[Memory/Logs/INDEX]] — date-routed monthly operational session history
- [[Memory/Weekly/INDEX]] — rollups only on explicit request
- [[Memory/Monthly/INDEX]] — rollups only on explicit request

No durable memory records are enrolled. Add a new memory note only when an existing owning note cannot hold it, then link it here. Operational history is exempt from per-record manual indexing.
