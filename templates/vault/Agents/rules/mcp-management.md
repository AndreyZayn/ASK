# MCP Management

First use the capabilities exposed by the current runtime. An inventory is descriptive; it does not prove a server is installed, connected, authenticated, or authorized. Diagnose missing tools, runtime configuration, network and authentication separately. Consult the relevant local integration record only as context.

Installing, removing, or changing an integration requires the owner's instruction and the runtime's actual permissions. Use the runtime's supported configuration mechanism, preserve unrelated entries, and verify the resulting connection without expanding scope. Never put credentials, tokens, private keys, or sensitive configuration values in the vault or logs; use the provider's supported authentication flow.
