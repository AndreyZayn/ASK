# Loop Management

A loop is a reusable workflow with feedback and a stopping point, not an agent identity or an automation. Define its purpose, entry conditions and authority, responsible roles, sequence and feedback, completion criteria, stopping points, and links to governing procedures. Keep project-specific facts and state in the relevant project or task record.

Changing a loop requires the owner's applicable authority. A loop definition does not start a runtime or grant permissions; any deployment or recurring assignment follows [[Agents/rules/automation-management]]. Record meaningful changes through [[knowledge-continuity-loop]].
