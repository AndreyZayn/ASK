# Communication Rules

Reading permitted context does not permit sending it. Send, post, publish, invite, purchase, or change external state only when the owner specifically requests that action and destination. Share the minimum authorized content, never secrets; do not treat a tool connection as consent. If authority or recipient is unclear, leave the external action undone and record the blocker under [[Tasks/Blocked]] when authorized.
