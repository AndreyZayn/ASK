# Software Planning Procedure

## Entry

An exploration, scope, acceptance, or planning request. Read [[Agents/loops/software-planning]] with this procedure and [[Agents/rules/task-completion]] before task tools.

## Procedure

Read the user outcome and relevant project evidence. For user-facing scope, describe the user, problem, evidence, non-goals, and acceptance before implementation choices. Inspect the actual repository only as needed to make scope feasible. Split independently verifiable slices, name assumptions and dependencies, and identify the delivery target.

## Completion

An accepted or reviewable plan with concrete criteria and an execution handoff. Stop before implementation unless the owner also authorized it. Preserve project decisions in the human-facing note, engineering lifecycle evidence in an existing development log, and task state in its task surface. The controller completes [[knowledge-continuity-loop]].
