# Software Release and Operations Procedure

## Entry

Explicit release, merge, deployment, operational observation, or incident authority. Read [[Agents/loops/software-release-operations]] with this procedure and [[Agents/rules/task-completion]] before task tools.

## Procedure

Confirm the actual target, approved revision, required checks, environment access, and recovery plan. Apply the authorized release through normal tooling. Observe the changed behavior in that environment. Return application defects to execution; distinguish infrastructure and permission blockers.

## Completion

The authorized release or observation result with revision, environment evidence, unresolved risk, and next owner. Preserve project decisions in the human-facing note, engineering lifecycle evidence in an existing development log, and task state in its task surface. The controller completes [[knowledge-continuity-loop]].
