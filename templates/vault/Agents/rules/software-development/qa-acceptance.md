# Software QA and Acceptance Procedure

## Entry

A testability, behavioral assessment, acceptance, or retest request. Read [[Agents/loops/software-qa-acceptance]] with this procedure and [[Agents/rules/task-completion]] before task tools.

## Procedure

Map criteria to representative tests, including relevant negative cases. Exercise rendered interfaces and persistence when applicable. Record environment and revision. Report reproducible defects, send scoped repairs to development, and retest affected behavior. Do not label unexercised surfaces as passed.

## Completion

An acceptance assessment with evidence, defects, and explicit untested criteria; this does not authorize deployment. Preserve project decisions in the human-facing note, engineering lifecycle evidence in an existing development log, and task state in its task surface. The controller completes [[knowledge-continuity-loop]].
