# Software Practice Improvement Procedure

## Entry

An evidence-based engineering workflow or harness diagnosis. Read [[Agents/loops/software-practice-improvement]] with this procedure and [[Agents/rules/task-completion]] before task tools.

## Procedure

Collect the smallest relevant incident evidence, identify the recurring mechanism, and propose a bounded correction. Separate failed tooling, missing authority, implementation defects, and instruction defects. Evaluate an authorized change against the original failure without turning diagnosis into broad rewrites.

## Completion

An evidence-backed diagnosis, recommendation, or verified authorized process change; no automatic installation or scheduling. Preserve project decisions in the human-facing note, engineering lifecycle evidence in an existing development log, and task state in its task surface. The controller completes [[knowledge-continuity-loop]].
