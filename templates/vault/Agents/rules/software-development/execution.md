# Software Execution Procedure

## Entry

Authorized implementation, fix, or accepted-plan execution. Read [[Agents/loops/software-development]] with this procedure and [[Agents/rules/task-completion]] before task tools.

## Procedure

Read live source and the project repository contract. Prepare the documented local environment, implement a focused change, and exercise relevant behavior and failures with synthetic fixtures. Inspect the complete diff. Obtain independent review for consequential permission, persistence, migration, or deployment changes when required by the project. Repair acceptance failures, rerun affected checks, and deliver only to the authorized target.

## Completion

A verified change at the requested local, commit, branch, or PR boundary, with exact evidence and remaining limitations. Preserve project decisions in the human-facing note, engineering lifecycle evidence in an existing development log, and task state in its task surface. The controller completes [[knowledge-continuity-loop]].
