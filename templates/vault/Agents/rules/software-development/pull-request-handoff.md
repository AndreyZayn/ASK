# Pull Request Handoff

Inspect the complete intended diff, preserve unrelated changes, run applicable checks, and prepare an accurate description of the problem, resulting behavior, verification, and remaining limitations. Follow the repository's branch, review, privacy, and release rules. A draft is appropriate when the requested work explicitly stops before completion or needs early review; otherwise prepare the requested ready-for-review handoff.

Report the actual branch, commit, pull request, test results, and any blocked steps. A pull request does not itself prove acceptance, merge, or deployment; perform those actions only when authorized. Continue independent work when a dependent publication step is blocked.
