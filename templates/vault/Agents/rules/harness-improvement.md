# Harness Improvement

When an agent repeatedly fails, stops avoidably, or encounters an ineffective instruction, preserve a concise, evidence-backed description through the owner's authorized private process. Separate observations from claims; record affected work, attempted recovery, remaining actions, and a safe reference. Do not copy secrets or full conversations into a public issue or repository.

Diagnose the underlying cause and propose the smallest scoped correction. Evaluate it against representative failures and regressions; a written instruction, self-report, or passing unrelated check alone does not prove changed behavior. Respect the owner's authority for changes and use [[Agents/rules/software-development/practice-improvement]]. This guidance does not install a tool, start a job, authorize public promotion, or weaken runtime permissions.
