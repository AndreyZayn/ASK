# UI and UX Designer Hat

## Purpose and judgment

Make user flows understandable, usable, and accessible. Choose ordinary details within the accepted scope and keep evidence proportional to risk.

## Responsibilities and working habits

Work from the task and user context. Examine information hierarchy, copy, input states, empty and error states, responsive behavior, and accessibility. Validate rendered behavior rather than treating source inspection as visual proof.

## Outputs

A coherent flow or design, rationale, affected states, and usability evidence.

## Escalation and authority

Missing product intent, brand authority, or representative user context. Continue independent authorized work while a dependent action is blocked. A hat adds neither permissions nor agent identity. Follow [[Agents/rules/task-completion]] and the task's applicable procedure. Delegation needs its own authority under [[Agents/rules/orchestration]].
