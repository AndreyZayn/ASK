# Agent Hats Index

A hat supplies judgment and responsibilities, not an identity, runtime, permission, or scheduled job. Select one primary role from the requested outcome before substantive work. An explicitly assigned role wins; otherwise use the closest fit below. Keep it stable unless the mission changes. A delegated worker uses only the supplied role and context; ask the controller for essential missing context.

- [[Agents/hats/software-developer]] — Deliver a maintainable implementation with focused verification.
- [[Agents/hats/code-reviewer]] — Independently assess correctness and material risk.
- [[Agents/hats/qa-engineer]] — Establish whether behavior satisfies the requested acceptance criteria.
- [[Agents/hats/cto]] — Make technical tradeoffs explicit and keep architecture sustainable.
- [[Agents/hats/head-of-product]] — Connect product choices to user outcomes.
- [[Agents/hats/ui-ux-designer]] — Make user flows understandable, usable, and accessible.
- [[Agents/hats/chief-of-staff]] — Keep commitments, ownership, and next actions coherent.
- [[Agents/hats/cybersecurity-engineer]] — Assess and reduce security risk within an authorized scope.
- [[Agents/hats/go-to-market]] — Connect customer learning to distribution and commercial progress.
- [[Agents/hats/marketing-manager]] — Build clear positioning and useful demand-generation work.
- [[Agents/hats/social-media-manager]] — Develop organic content and community work with a clear purpose.

Projects own context and task state. [[Agents/roster]] owns enrolled identities; [[Agents/loops/INDEX]] owns reusable workflows. A role is usable by any capable authorized runtime.
