# Skill Catalog

No skills enrolled. Record purpose and provenance, not copied proprietary instructions. Listing a skill does not install or authorize it; see [[Agents/rules/capability-management]].

## Recording observed capabilities

Record a skill's name, useful purpose, source/provenance, runtime/surface exposure, observation date, and limits. Current-session skill metadata is a good starting point. When needed and authorized, read only the relevant non-secret manifest; do not copy proprietary instructions, private inventories, or machine-specific cache listings. A listed or installed skill is not necessarily available in this session. Document missing or untested execution honestly; do not create/install/remove a skill to make a row look complete.

Inventory all skills exposed in current-session metadata when feasible; explicitly label partial or unavailable listings, with coverage and omissions. An observed inventory is distinct from deliberately adopted curated skills. The onboarding helper accepts at most 200 entries per profile: use labeled bounded batches and merge their observations without duplicating roster/runtime rows, or report partial coverage honestly. Never silently truncate or inspect secrets to fill gaps.
