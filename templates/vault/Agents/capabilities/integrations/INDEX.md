# Integration Catalog

No integrations enrolled. Keep tokens, service endpoints containing credentials, and authentication configuration outside notes and Git. An entry is descriptive, not permission to act; see [[Agents/rules/communications]].

## Recording observed capabilities

Record the capability and service boundary without account identifiers, credential-bearing endpoints, tokens, or raw authentication data. Distinguish an exposed tool, configured connection, and a specific successfully observed operation. Only an already authorized harmless scoped operation can support live verification; catalog work never authorizes sending, spending, resource creation, or new authentication. Record an inaccessible operation as unavailable/unknown with the narrow next action.
