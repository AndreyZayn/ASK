# Runtime Catalog

No runtime registrations. Record only owner-approved runtime name, purpose, verification state, and locally enrolled ID. Actual authentication and filesystem permissions live outside this vault. See [[Agents/roster]].

## Recording observed capabilities

For each relevant runtime, record its surface, locally enrolled agent ID, bootstrap enrollment state, observed verification evidence, date, and known limits. Use actual runtime status and fresh-session proof; a generated proposal deliberately leaves availability unknown. A CLI result does not prove desktop, hosted, connected-machine, or scheduled behavior. Keep credentials and provider settings outside this catalog. Preserve other workspace bindings and agents' evidence.
