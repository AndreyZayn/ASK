# Agent Automations Index

This catalog starts empty. A workflow definition is not a schedule. Record an automation only after the owner requests it, with purpose, owner, trigger, bounded context, expected output, stop conditions, and dated deployment evidence. Keep credentials and raw runtime payloads out of the vault. Live runtime configuration determines whether it is enabled; a note cannot deploy or authorize it.

Load [[Agents/rules/capability-management]] before changing a runtime, and [[Agents/rules/orchestration]] before delegating. Link the relevant definition under [[Agents/loops/INDEX]].
